DWFS

Turn any picture into one continuous line, then watch spinning circles draw it.

PythonMIT

View on GitHubTry it in your browserdwfs on PyPI

About

DWFS traces a picture into a single closed path, works out its Fourier series, and opens a window where two chains of circles redraw it, sharpening from a rough loop into the exact drawing as more terms are added.

It handles line drawings, photos, logos, flags and SVG files, and it can write text in one continuous line in any script your fonts cover, Nepali and other joined scripts included.

Highlights

  • Detects whether it was given a line drawing, photo, logo or flag
  • Traces one continuous route along the strokes and lifts the pen over short gaps
  • Grows the number of terms pass by pass and shows the approximation error live
  • Interactive window with a timeline and one click saving to MP4, GIF or PNG
  • Runs from the command line or as a Python library

Quick start

pip install dwfs
dwfs make photo.jpg
dwfs text "Hello World"
