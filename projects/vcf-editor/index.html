About

Cardfile is a free alternative to paid vCard editors. Open .vcf files, edit contacts, merge files and create new cards. Everything happens on your device, so your contacts never leave it.

It is a single installable web app that keeps working offline.

Highlights

  • Edit, merge and create .vcf files
  • Runs entirely in the browser, nothing uploaded
  • Installable and works offline
