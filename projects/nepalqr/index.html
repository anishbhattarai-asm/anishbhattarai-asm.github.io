nepalqr

Turn a merchant's free static NepalQR into a dynamic QR that carries the amount.

About

A Nepali merchant QR is an EMVCo Merchant-Presented Mode payload. nepalqr decodes the merchant's existing static QR, sets the amount for each order, marks it dynamic and recomputes the checksum, so the customer scans and sees the amount already filled in. No payment aggregator and no integration fees.

It was tested against real Fonepay merchant QRs: the library reproduced the issuers' own checksums byte for byte, and a Rs 1.00 dynamic QR scanned with eSewa settled. The README is clear about the limits: that is one acquirer at one point in time, and whether you are permitted to do it is a separate question.

The repo also includes a web app that runs entirely in the browser: scan the static QR once, type an amount, and show the dynamic QR. It installs to the home screen and works offline.

Highlights

  • Zero dependencies
  • Decode, inspect and rebuild EMVCo QR payloads
  • Track open tabs and parse bank credit alerts for reconciliation
  • Installable offline web app with a camera scanner

Quick start

import { withAmount } from 'nepalqr';

const dynamicQR = withAmount(merchantStaticQR, 450.37);
