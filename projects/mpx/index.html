MTPX

Write Manim animations as ordinary Python methods and get a PowerPoint deck where each method is one click.

PythonMIT

About

Each @slide method is one click step. All slides share one Manim scene, so objects you keep on self persist from slide to slide and the deck plays as one continuous animation: the slide changes are invisible.

Open the generated .pptx, press F5 and click. Each click advances a slide and its animation plays automatically. Slides run in source order, and a method without animation becomes a still image.

Highlights

  • One method is one click, however many animations it plays
  • Continuous animation across slides, with no visible cuts
  • Holds each slide on its settled state so nothing flickers on the next click
  • Needs only manim, the pptx library and ffmpeg

Quick start

from manim import *
from mtpx import SlideScene, slide

class Demo(SlideScene):
    @slide("A square appears")
    def square(self):
        self.sq = Square(color=BLUE, fill_opacity=0.5)
        self.play(Create(self.sq))

    @slide("It moves")
    def move(self):
        self.play(self.sq.animate.shift(2 * RIGHT))
