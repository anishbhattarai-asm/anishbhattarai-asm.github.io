About

Each attractor's differential equations are integrated with a fixed-step RK4 solver and drawn as glowing neon curves with drifting particles. Manim renders the clean geometry, Blender adds a physically soft glow, and DaVinci Resolve applies the final colour grade.

It includes the Halvorsen, Lorenz, Aizawa and Thomas attractors, with a fast GPU path through Blender or a CPU path through Manim.

Highlights

  • Math in Manim, bloom in Blender, grade in DaVinci Resolve
  • Four attractors: Halvorsen, Lorenz, Aizawa and Thomas
  • GPU render path for speed, CPU path when Blender is not installed
  • Parameters and integration settings at the top of each scene file
